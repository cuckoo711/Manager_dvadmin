# 适用于django-vue3-admin的定时任务插件前端



## 特性：



1.支持前端添加定时任务

2.前端开启/停用定时任务

3.前端查看任务运行日志，结果，状态等信息

4.前端手动执行任务



## 注意：dvadmin3-celery-web支持后端dvadmin3-celery版本为3.1.0之后版本



## 使用：


选一即可，使用你喜欢的npm包管理器

```js
npm install dvadmin3-celery-web

yarn add dvadmin3-celery-web

pnpm add dvadmin3-celery-web
```
